## About

My personal portfolio website showcasing my projects, skills, and background as a Computer Science student focused on full-stack development and AI-powered applications. Built to target internships, software engineering roles, and collaboration opportunities.

## Tech Stack

| Layer | Technologies |
|---|---|
| Frontend | Next.js, React, Tailwind CSS, Framer Motion |
| Language | TypeScript |
| UI Components | Aceternity UI, shadcn/ui |
| Deployment | Vercel |

## Features

- **Hero** — Spotlight animation with a text-generate effect
- **Bento Grid** — About section with photo, tech stack pills, globe, and contact card
- **Projects** — Pin cards for VistaTribe, PrashanGPT, and BookAid with live + repo links
- **Testimonials** — Infinite scrolling cards from mentors and professors
- **Experience** — Student-focused development experience cards
- **Approach** — Three-phase developer workflow with canvas reveal effects
- **Contact Modal** — Animated popup with LinkedIn, GitHub, and copy-to-clipboard email
- **Fully Responsive** — Works across all screen sizes

## Getting Started

```bash
# Clone the repo
git clone https://github.com/Prashan33/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
